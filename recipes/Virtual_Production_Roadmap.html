How to use this guide

01 / LEARN

Read → reproduce

Use the linked official tutorials and docs. Some are structured courses; many advanced topics only have documentation. Give each topic a small test in Unreal.

02 / PROVE

Show the output

Check a task only when you can repeat it. Save the project, a short capture, a system diagram and a short issue log.

03 / ITERATE

Return to gaps

Phases are ordered by dependency, not rigid calendar appointments. Build the broadcast core first; fit vendor work around actual system access.

Your first move

Open Phase 00, draw the three signal paths, then create a clean Unreal project. Weeks are estimates at 10–12 focused hours per week. Treat the course list as a map, not a guarantee of expertise.

Correction to the earlier roadmap: You should start camera, timing and signal-flow concepts early, then deepen them with hardware. Vendor platforms can be learned alongside the core once access is available; waiting until month 15 would waste useful studio time. Unreal 5.8 documentation is the current reference checked here, but use the engine version required by your facility.

Proof of capability

Portfolio ladder

01 / DESKTOP

Real-time studio + live graphics

3D import, lighting, camera, measured frame time, scoreboard and an operator panel. Record the end-to-end demo.

02 / TRACKED AR

Floor-locked football graphic

Tracked camera, calibrated lens, occlusion, shadows and alignment across pan, tilt, dolly and zoom. Document failure and correction.

03 / GREEN SCREEN

Sports tactics virtual studio

Presenter, tactical pitch, XI and statistics. Match perspective, key, color, timing and control from a real operator interface.

04 / LED XR

ICVFX stage test

nDisplay config, tracked inner frustum, LED output, synchronization and color pipeline. A single-node simulation comes before a real stage.

DESKTOP

You can start now

Unreal, Datasmith/FBX, Blueprints, Motion Design, Remote Control, simulated tracking, Composure tests, profiling and nDisplay configuration.

EQUIPMENT

Real validation needs a stage

SDI I/O, reference sync, tracked lenses, keying, accurate AR alignment and LED color/sync need compatible equipment and staff access.

EXPERTISE

Courses are insufficient

Expert means building, operating and diagnosing repeatable productions under a defined format, frame rate and failure budget.
